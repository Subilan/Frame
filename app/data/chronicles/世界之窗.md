# 世界之窗

2017 年，表姐 Vanas 邀请我来到深圳。

<!-- excerpt -->

这是我第一次来到南方、来到深圳，给我留下了挥之不去的印象——一种不同于当时还去过的哈尔滨、北京和青岛的印象。

![深圳的街道](dawanqu/2017/2017.08.13_10.33.57.JPG "傍晚的街道")

或许是因为这里有热带的湿热、鲜艳的花草、山雾与海浪和说下就下的特大暴雨，还伴随着一种多元又丰富的现代氛围。

::: split-right
![夜色中的城市](dawanqu/2017/2017.08.13_21.11.14.JPG "夜晚的城市")

“这里和其他地方，有很大的不一样。”
:::

::: split-left
![世界之窗](dawanqu/2017/2017.08.13_20.55.08.JPG "世界之窗")

它一定程度上改变了我看待未来和可能性的方式。
:::
